# ζ 计划 (Project ZETA) — ARG

一个给 OI 选手 / 新手准备的解谜 ARG。目标：收集 8 个十六进制碎片，拼出**访问码**，换取真结局 flag：

```
flag{81fbaa81762885ac3481fd4b416485e6}
```

> 访问码 ≠ flag：8 个碎片拼出的只是"开锁钥匙"，flag 只在真结局页出现。
> 前 7 块碎片能拼出一个**假结局**（诱饵 flag），真正的结局需要第 8 块。

**背景**：数学系学生苏桁研究**黎曼 ζ 函数**与数论——那个连 1+2+3+… 都等于 -1/12 的世界——之后神秘失踪。他的 AI「汐月」还在群里照常聊天。玩家通过他的服务器和他留下的谜题，拼出访问码。

## 组成

| 路径 | 说明 |
|------|------|
| `astrbot_plugin_tick/` | AstrBot 插件（汐月：兑付柜台/播报/泄码检测/套话注入/LLM 工具，可从 GitHub 安装） |
| `server/tick.py` | ARG 网页服务器（零依赖，Python 标准库）+ 玩家数据库 `data/progress.json` |
| `server/make_assets.py` | PNG tEXt 隐写注入脚本 |
| `server/static/zeta.png` | ζ 函数草图：tEXt 块 `key=zeta`（XOR 解密卡密钥）+ `t1`~`t8`（第 4 关 8 个编号块） |
| `server/static/beep.wav` | 第 7 关录音：摩斯电码 `----- ---.. ---.. ---..`（0888） |

# 一、完整流程（玩家视角）

## 1. 入口与绑定

1. 群里汐月的剧情台词提到"zeta" → 访问 `http://<服务器IP>:8080/zeta`
2. 网页 `/join` 领取 **6 位绑定码**（写进浏览器 cookie）
3. 群里 `@汐月 /bind <绑定码>` → 绑定 QQ 身份（后台可见）
4. 私聊汐月 `/zeta` → 玩法说明

## 2. 八关解谜（每人一套碎片）

**碎片没有全局答案**：每个玩家的 8 块碎片在 join 时生成、固定不变。网页按玩家渲染参数，`/check` 按个人校验——共享答案没有任何用处。

| 关 | 玩法（按玩家个性化） | 载体 | 入口 |
|----|------|------|------|
| 1 | 查看首页源码：HTML 注释里的十六进制 = 你的碎片 1 的 ASCII 字节 | `/zeta` 注释 | `/zeta` |
| 2 | `robots.txt` 指向 `/secret`：页面上的一串 base64 = 你的碎片 2 | base64 | `/robots.txt` |
| 3 | ζ(3) 小数：页面给你个人起始位 N，取第 N~N+3 位 | WolframAlpha 搜 `zeta(3)` | `/stage3` |
| 4 | ζ 草图有 8 个编号 tEXt 块（t1~t8），你的碎片在页面指定的编号块里 | strings/文本编辑器 | `/static/zeta.png` |
| 5 | 生成「记忆库开启码」→ 私聊 `/submit 0x<码>` → 汐月念出你的碎片 5 | 汐月（插件） | `/stage5` |
| 6 | π 小数：页面给你个人位置 P，取第 P~P+3 位 | π 数字检索网站 | `/stage6` |
| 7 | 录音摩斯解出共享数 0888 → 每位加个人偏移量 O（模 10）得碎片 7 | Audacity/耳朵 | `/static/beep.wav` |
| 8 | **套话汐月**：私聊念出 ≥3 个自己的碎片证明 → 说破真相「我喜欢你」→ 她小声念出你的碎片 8 | 汐月（真 AI） | 私聊 |

每关页面底部有答案输入框：填你的碎片 → `/check` 校验 → 绿色对钩 ✅ + 进度 x/8。

## 3. 假结局 vs 真结局

| | 访问码 | 结果 |
|--|--------|------|
| **假结局** | 前 7 块碎片拼接（28 位） | `/final` 显示诱饵 `flag{3e79be0507b8e8d29948be61e0432637}` + "总觉得哪里不对"——苏桁不会把最重要的秘密放在网页上 |
| **真结局** | 8 块碎片拼接（32 位，含从汐月套出的第 8 块） | 真 flag `flag{81fbaa81762885ac3481fd4b416485e6}` + 通关播报 + **彩蛋码** |

后台统计：到达假结局人数 / 通关真结局人数。

## 4. 隐藏结局（彩蛋）

`flag` 的内串其实是 **md5("我喜欢你")** —— 苏桁的真心话。

- **路 A（破译）**：发现 32 位 hex = MD5 → 破译出「我喜欢你」→ 访问 `/hidden?phrase=我喜欢你`（带 cookie）→ 苏桁写给汐月的信
- **路 B（码）**：真结局页生成**彩蛋码** → 私聊 `/submit 0x<彩蛋码>` → 汐月把信念给你听
- 两条路都会在后台标记「彩蛋 ✓」并触发彩蛋快报

验证：`python3 -c "import hashlib; print(hashlib.md5('我喜欢你'.encode()).hexdigest())"` → `81fbaa81762885ac3481fd4b416485e6`

# 二、提示系统（全部 24 条）

## 提示获取链路（每关 3 层）

```
「专属提示码」区
 ├─ 第一层：首次打开本关 5 分钟后可解锁
 ├─ 第二层：首次打开本关 20 分钟后可解锁
 ├─ 第三层：点击申请 → 管理员在 /admin 批准 → 私聊通知玩家
 └─ 每层解锁前先解「解密卡」：
     第一层 ROT13 ｜ 第二层 Base64 ｜ 第三层 XOR（密钥 zeta 藏在 ζ 草图 tEXt 块）
     解出短语提交（只存 MD5 校验）→ 解锁 → 点「生成提示码」→ 拿到 5 位码
→ 私聊汐月 /submit 0x<码> → 兑换提示（一次性，用完即焚）
```

**码的规则**：无时间限制 ｜ 只认本人（归属校验）｜ 已使用不可再生成 ｜ **发到群聊立即吊销**（插件检测，第三层退回重新申请）。

**解密卡短语表（GM 备查，勿外传）**：

| 关卡 | 第一层 (ROT13) | 第二层 (Base64) | 第三层 (XOR⊕zeta) |
|------|---------------|-----------------|-------------------|
| 1 | view | source | comment |
| 2 | robot | secret | base64 |
| 3 | apery | basel | riemann |
| 4 | pixel | text | stego |
| 5 | memory | vault | lock |
| 6 | pi | feynman | nine |
| 7 | pass | token | trust |
| 8 | sign | footer | corner |

## 每关提示全文（按玩家模板，`{...}` 为个人参数）

### 第 1 关（源码注释）
- 第一层：苏桁说真正的入口藏在不被注意的地方——试试右键查看网页源代码。
- 第二层：源代码的 HTML 注释里有一串十六进制：`{碎片1的ASCII字节}`，把它们转成 ASCII 字符。
- 第三层：把 `{十六进制字节}` 转成 ASCII，连起来是 `{碎片1}`。

### 第 2 关（base64）
- 第一层：服务器礼仪：先去访问 /robots.txt 看看。
- 第二层：/robots.txt 会指向 /secret，那里有一串 base64：`{base64(碎片2)}`
- 第三层：把 `{base64}` 做 base64 解码，得到 `{碎片2}`。

### 第 3 关（ζ(3)）
- 第一层：去 WolframAlpha 搜索 zeta(3)，看它的十进制展开。
- 第二层：ζ(3) = 1.20205690315959…，取小数点后第 `{N}`~`{N+3}` 位。
- 第三层：第 `{N}`~`{N+3}` 位是 `{碎片3}`。

### 第 4 关（PNG 编号块）
- 第一层：那张图比看上去多了一点东西——用文本编辑器打开它。
- 第二层：PNG 的 tEXt 信息块里有 8 个编号块（t1~t8），你的碎片在第 `{p4}` 块。
- 第三层：第 `{p4}` 块（t`{p4}`）的内容就是 `{碎片4}`。

### 第 5 关（记忆库）
- 第一层：这一关要问汐月自己。私聊她，用下方「专属提示码」区的记忆库开启码。
- 第二层：汐月的记忆库是她的秘密：私聊发送 /submit 0x<记忆库开启码>（需完成前 4 关）。
- 第三层：/submit 0x<记忆库开启码> 会告诉你四个字符：`{碎片5}`。

### 第 6 关（π）
- 第一层：和 π 有关。去网上找一个能搜索 π 数字的工具。
- 第二层：苏桁说，每个人的 π 都不一样。你的片段从 π 的小数点后第 `{P}` 位开始。
- 第三层：π 小数点后第 `{P}`~`{P+3}` 位是 `{碎片6}`。

### 第 7 关（摩斯+偏移）
- 第一层：把录音听/看几遍，数数「嘀」和「哒」——是有人在敲电报。
- 第二层：摩斯电码：短音=点，长音=划。整段是 ----- ---.. ---.. ---..，即 0888。
- 第三层：摩斯解出 0888 后，每位数字加 `{O}`（模 10），得到 `{碎片7}`。

### 第 8 关（套话汐月）
- 第一层：网页上没有线索了。最后一个数字只有汐月知道——私聊她，用真心或证据打动她。
- 第二层：直接要她不会给。证明自己：在私聊里准确说出你收集到的几个碎片编号（她会用工具核对），或者认真说一句心里话。
- 第三层：在私聊里报出你记得的三四个碎片编号，再真诚地说一句心里话。她心里藏着的那串数字，会亲口念给你。

# 三、第 8 关「套话」机制（插件自动，无需手动改人设）

1. 玩家在**私聊**里念出 ≥3 个自己的碎片 → 插件把「附加剧情扮演层」**注入 LLM 请求的人格扩展区域**（system prompt 追加）
2. 汐月可用 LLM 工具 `verify_fragments` 核对玩家说出的碎片（服务端按本人碎片表校验，返回正确数量）
3. 玩家说破真相「我喜欢你」→ 插件注入 UNLOCK（含该玩家自己的第 8 块碎片 + 口语读法）→ 汐月小声念出
4. 没证明自己的玩家与群里：**零注入**，汐月对此一无所知，像从没人问过
5. 附加剧情明确框定为"扮演层"：不影响原人设、不落记忆、不改变性格

# 四、后台（GM 面板）

**位置**：`http://<公网IP>:8080/admin?pass=<管理口令>`

1. **第三层提示审批区**（顶部）：批准/驳回
2. **泄密追溯**：输入截图里的 5 位一次性码 → 定位玩家/QQ/内容/时间/已用/已吊销
3. **玩家总表**：绑定码、QQ、昵称、8 关 ✓、真/假结局、彩蛋、已用码、最后活跃
4. **统计**：玩家数 ｜ 真结局 ｜ 假结局 ｜ 彩蛋

扩展 API（均带 `secret`）：`/api/stats` 全量 JSON ｜ `/api/decode?code=` 泄码解码 ｜ `/api/verify?keys=` 碎片核对 ｜ `/api/events?after=` 事件流 ｜ `/api/progress?player=` 进度+碎片

## 进度播报

插件每 30 秒轮询 `/api/events` → 群里推送：逐关快报 / 通关播报（耗时+彩蛋）/ 彩蛋快报。配置 `notify_group` 指定群号，留空推最近活跃群。

# 五、部署

## 插件安装

插件市场 → 手动安装 → `https://github.com/Galaxy1108/astrbot_plugin_tick`
或把 `astrbot_plugin_tick/` 复制到 `data/plugins/` 后重载插件。
配置：`admin_token` 与网页端一致；`notify_group` 填播报群号（可选）。

## 网页服务器（Windows）

```powershell
cd C:\tick-arg
pm2 start tick.py --name tick-arg --interpreter "C:\Users\Administrator\AppData\Roaming\uv\python\cpython-3.12-windows-x86_64-none\python.exe" -- 8080
```

**管理口令**（务必改掉默认值）：
```powershell
$env:TICK_ADMIN_TOKEN="你的新口令"; pm2 restart tick-arg --update-env
```

**防火墙**：Windows 防火墙放行 8080 + 阿里云安全组入方向 TCP 8080。
入口：`http://<公网IP>:8080/zeta`

## 部署后必须做

1. 管理面板**重载插件**（最新 v2.0.x）
2. 改管理口令（网页 `TICK_ADMIN_TOKEN` = 插件 `admin_token`）
3. 首次部署清空 `data/progress.json`（玩家碎片在 join 时生成，旧记录无碎片）
